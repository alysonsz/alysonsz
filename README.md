## Sobre

Sou **Engenheiro de Software Full-stack**, com base forte em **.NET e backend** e experiência em produtos web e mobile.

Meu trabalho envolve modelar regras de negócio, definir responsabilidades entre camadas e integrar sistemas que precisam funcionar mesmo quando uma dependência externa falha. Atuo também na interface quando isso ajuda a entregar o produto completo.

## Método XYZ

**X · eXperience**  
Entendo o fluxo de quem usa o produto antes de definir contratos e persistência. Na Oria, uma sugestão de compromisso passa pela confirmação do usuário; a IA não grava eventos diretamente no calendário.

**Y · Yield**  
Transformo restrições em decisões técnicas. No Nexo, classificação e roteamento por custo ficam na camada de aplicação, enquanto o backend mantém o catálogo de modelos. A resposta chega à interface em eventos NDJSON.

**Z · Zenith**  
Levo a solução até a operação. No Nucleus, isso inclui lidar com falhas nas integrações de Open Finance, preservar a consistência dos dados e automatizar mais de 500 cenários E2E.

## Projetos em destaque

### Nucleus

**Produto financeiro autoral · 2026**

Construí o aplicativo em **React Native**, o backend em **.NET** e a experiência web em **Next.js**. O produto reúne dados financeiros de diferentes fontes e ajuda o usuário a entender o que mudou.

No backend, trabalhei na consolidação de dados, nas integrações de Open Finance e no tratamento de falhas de serviços externos. Os fluxos críticos têm mecanismos de consistência e fallback, além de **mais de 500 cenários E2E automatizados**.

**[Visitar o produto →](https://nucleusbrasil.com.br)**

### Oria

**Assistente pessoal · Mobile + API · Em desenvolvimento**

Aplicativo em **Expo e React Native** para acompanhar agenda, tarefas e conversas, com API em **.NET** e dados em **PostgreSQL**.

O backend separa domínio, casos de uso, infraestrutura e HTTP. A integração com modelos fica no servidor, onde também são controlados tempo de resposta, retentativas e fallback. O aplicativo lê calendários disponíveis no aparelho dentro de um período limitado; nomes de eventos não são compartilhados por padrão. Antes de criar um compromisso sugerido pela IA, o usuário confirma os dados.

[App →](https://github.com/alysonsz/oria-mobile) ![Private](https://img.shields.io/badge/Private-555?style=flat-square) · [API →](https://github.com/alysonsz/oria-backend) ![Private](https://img.shields.io/badge/Private-555?style=flat-square)

### Nexo

**Workspace de IA · Web + API · Em desenvolvimento**

Interface em **Next.js** com API em **.NET** para conversas com seleção de modelos e respostas em streaming.

A classificação da solicitação e a decisão de rota ficam na camada de aplicação. O catálogo de modelos é mantido no backend, sem uma segunda lista no frontend. A API transmite eventos **NDJSON** de rota, conteúdo e conclusão. Biblioteca e preferências são associadas a uma sessão em cookie **HttpOnly**; chaves não são armazenadas no `localStorage`.
